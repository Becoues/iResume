# iResume 面试前准备工作台

用户已确认：聚焦紧急面试前准备，取消语音和面试中功能；支持非 PDF 简历；完成实际部署并交付可访问 URL。沿用已有 Next.js 15.5.28 / Prisma 项目。

## 产品
- 上传或粘贴简历，可选 JD，一次操作生成简报。
- 支持 PDF、DOCX、DOC、TXT、Markdown、RTF、PNG/JPEG/WebP；图片与扫描 PDF 使用 OCR，明确显示提取提示及限制。
- 首屏为候选人速览、最多三段相关经历、最多三个待核实点、三至五道优先问题。展开查看来源、听取重点及追问。
- 结论应区分事实和待验证判断；引用必须能在原文找到。无依据不得生成确定性评价。
- 详细问题按需生成。保留历史报告数据，新界面不再展示录音入口。
- 简洁中性色、蓝色强调色、桌面与移动端可用、可打印简报。
- 不自动决定录用，不推断敏感个人属性。

## 架构选择
比较：纯 UI 美化不能完成工作流变化；整站重写增加迁移风险；选择现有栈上的渐进重构。
连接层支持 CometAPI、OpenAI 兼容接口及 Bedrock。快速简报与深入准备共享类型和证据规则。
独立持久化运行记录，冻结配置，原子认领，成功结果保留，失败与超时明确反馈。
SQLite 保留单实例部署；正式迁移不删除旧字段或旧数据。部署维持访问保护，服务器端保管模型凭据。

## 验收
真实文件解析、输入限制、无模型配置的清晰错误、实际模型生成、重试不丢旧结果、并发重复请求、刷新恢复、响应式 UI、打印、无录音入口。
发布前运行单元/接口测试、typecheck/build、浏览器验证和线上健康检查。
